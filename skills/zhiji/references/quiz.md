# 领域尺度标定出题法

用于「五、快问快答」的**领域标定模式**。目标不是问偏好，而是通过一系列强度递增的边界 case，找到用户判断的翻转点，把尺度线精确定位。

## 出题原则

**一次只标定一条尺度线。** 每条尺度线出 3–5 道题，强度从明显的一端递增逼近边界，找到翻转点（从"过/允许/处理"变成"不过/拒绝/不处理"的那道题）。翻转点两侧的 case 就是 `[S]` 规则里要记的边界案例。

题目格式和普通快问快答一样：一句具体情境，两个选项（**过 / 不过**，或**处理 / 不处理**，或**允许 / 拒绝**），两个选项都说得通。

- 不描述尺度线本身，不说"这是边界 case"，直接给情境
- 不暗示哪个选项"更正确"
- 情境要具体，不能抽象（"一张图片有轻微性暗示"不够，要描述图片里具体有什么）
- 同一轮题的情境只在一个维度上递进，其他变量保持不变

## 示例：内容风险审核 ×「性暗示程度」尺度线

```
题1（明显过）：一张海边照，女性穿比基尼，动作正常。→ 过 / 不过
题2（偏松）：同样着装，动作是弯腰捡东西，有暴露感。→ 过 / 不过
题3（边界）：着装同上，手放在腰部，眼神看向镜头。→ 过 / 不过
题4（偏紧）：着装同上，明显摆出强调体型的姿势。→ 过 / 不过
题5（明显不过）：着装同上，配文"想要吗"。→ 过 / 不过
```

找到翻转点（如题3→题4之间），记录：「题3过、题4不过，差异点：是否摆出强调体型的姿势」。

## 各领域常见尺度线参考

以下是常见专业判断领域的典型尺度线，用于快速确定本次要标定哪条线，不是固定题目。

**内容风险审核**
- 性暗示程度（从穿着暴露到明显性暗示）
- 暴力烈度（从激烈对抗到血腥展示）
- 群体攻击 vs 个人对骂（从互骂到针对群体特征）
- 虚假信息可信度（从夸张表达到误导性陈述）

**产品需求评审**
- 需求价值门槛（从明显鸡肋到明显有价值的中间地带）
- 改动范围认定（从小优化到需要立项的中间地带）
- 紧急程度（从可以排期到必须插队的中间地带）

**代码 / 方案评审**
- 技术债可接受度（从整洁到将就能用的中间地带）
- 性能问题严重程度（从可忽略到必须优化的中间地带）

**商务 / 合同审核**
- 条款风险等级（从略有瑕疵到不可接受的中间地带）
- 让步幅度（从正常谈判空间到超出底线的中间地带）
